# Anna Avatar Version

This folder keeps the avatar-enabled Swift/web build separate from the school-focused learning version in the project root.

Run the avatar Swift app from this folder:

```bash
cd AvatarVersion/SwiftAnna
swift run AnnaSwift
```

Run the avatar web server from this folder:

```bash
python3 AvatarVersion/Webversion/server/web_agent_server.py
```

The active project root remains the non-avatar learning version.
